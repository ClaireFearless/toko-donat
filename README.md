# 🍩 Toko Donat

**Toko Donat** adalah sebuah **Fullstack Application** yang dikembangkan menggunakan **Flutter** sebagai *frontend* dan **Laravel** sebagai *backend*.

Project ini dibuat sebagai **tugas kerja kelompok**, dengan tujuan menerapkan konsep pemisahan frontend dan backend serta penggunaan **REST API** dalam pengembangan aplikasi modern.

---

## 🎯 Tujuan Project
- Menerapkan arsitektur **Fullstack Application**
- Mengimplementasikan **REST API** menggunakan Laravel
- Menghubungkan aplikasi Flutter dengan backend
- Melatih kerja sama tim dalam pengembangan perangkat lunak

---

## 🛠️ Teknologi yang Digunakan

### Frontend
- Flutter
- Dart

### Backend
- Laravel
- PHP
- Database (MySQL / SQLite)
